# Fanta-stic
A (totally serious) visual novel about a troubled character who bounces back, but faces the wrath of the people he hurt in the afterlife. <br>

### How to play: 
Click "Run game" on [keltime.itch.io/fanta-stic](https://keltime.itch.io/fanta-stic) and enjoy!

This game was created in Ren'py <br>
